# Real-Time-Currency-Converter
Real-time Currency Converter built with JavaScript, HTML, and CSS using live REST APIs and dynamic country flag rendering.

🚀 Features

 **Live Rates:** Real-time exchange rate updates powered by REST API.
 **Dynamic Flags:** Country flags automatically update via FlagsAPI based on selected currency.
 **Input Protection:** Gracefully handles empty or negative input values.
 **Modern UI:** Built with a clean dark theme, responsive layout, and FontAwesome icons.

 📁 Folder Structure
├── index.html    # Main UI markup
├── style.css     # Styling & Dark theme layout
├── codes.js     # Currency-to-country code mappings
└── logic.js     # API fetching & event listener logic
